# さくらんぼ計算 でんしゃランド (Learn Sakuranbo Method)

小学1年生向けの「さくらんぼ計算（繰り上がりの足し算・繰り下がりの引き算）」をステップバイステップで楽しく学べるWebアプリ（PWA対応）です。

- **公開URL (GitHub Pages)**: https://teleclimberaikawa0526-afk.github.io/Learn_Sakuranbo_Method/

## 主な機能

- **ステップバイステップ学習（全3コース）**
  - 🍒 **たしざん（くりあがり）**: 10をつくる相棒 → のこりをわける → 10とあわせて答え
  - 🍒 **ひきざん（くりさがり・減加法）**: 10といくつにわける → 10からひく → のこりをたす
  - 🌈 **ミックス チャレンジ**: たしざん・ひきざんの両方がランダムに出題
- **視覚サポート（数図ブロック）**: 10のまとまり（テンフレーム）で数の動きを直感的に理解（ON/OFF切替可）
- **子供キャラクター風の音声ガイド**: 各ステップのガイド・ほめ言葉・ヒント・ガチャ・図鑑解説を音声で読み上げ（聞き直し＆ON/OFF切替可）
- **ごほうびマイル＆でんしゃガチャ・ずかん**:
  - 1ステップ正解ごとに **+1マイル** 獲得
  - **10マイル** ごとに「でんしゃガチャ」を回して全110種類の電車をコレクション
  - データの引き継ぎ（コピー＆復元）対応

## セットアップ・起動方法

```bash
# パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番ビルド
npm run build
```

## 音声ファイルの再生成（任意）

ガイド文言を変更した場合、以下のスクリプトで音声ファイル（`public/voices/`）とマニフェスト（`src/data/voiceManifest.ts`）を再生成できます（要 Python + `edge-tts`）。

```bash
pip install edge-tts
python scripts/generate_voices.py
```
